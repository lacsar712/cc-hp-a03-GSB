# 饮片炮制记录台

一条记录是一整包炮制文书，里面是工序数组，不是拆成多列指标的普通表单。清炒温度和时长不在范围内就不能放行。

每口锅须挂校准证书编号才能开炒。炮制员在证书台登记锅名与证书号，证书可标作废；写入记录时必须挑一口证书仍有效的锅，无证或已作废会被拒写。作废动作写入证书大事记；改正锅名不影响已挂证书号。质检员能看证书台与大事记，不能登证、不能作废。

## 验收

1. processor 登录后，甘草为放行，黄芩为未放行（温度过低）。
2. 顶栏进证书台，登记甲锅与证书号；回记录台挑甲锅写黄芩，应成功。
3. 证书台把甲锅证书作废，大事记出现作废记录；再挑甲锅写入应被拒。
4. 证书台落地页上半列有效证书、下半列大事记；改正锅名后证书号不变。
5. checker 能看证书台与大事记，但看不到登记、作废、改名入口，也看不到写入按钮。
