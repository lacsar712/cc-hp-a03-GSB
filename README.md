# 饮片炮制记录台

一条记录是一整包炮制文书，里面是工序数组，不是拆成多列指标的普通表单。清炒温度和时长不在范围内就不能放行。

每口锅必须先在证书台挂校准证书编号才能开炒：写入记录时必须挑一口证书仍有效的锅，无证或证书已作废一律拒写。证书台在顶栏有入口，上半列有效证书，下半列证书大事记（登记、改名、作废都进大事记）。改正锅名不动已挂的证书号；证书作废后可重新登记新证。

## 验收

1. processor 登录后，甘草为放行，黄芩为未放行（温度过低）。
2. 顶栏进「证书台」，给甲锅登记证书号（如 CAL-2026-001），有效证书列表出现甲锅，大事记出现一条登记。
3. 回「记录台」选甲锅写一条黄芩（清炒 120℃、12 分钟），写入成功。
4. 再写一条温度 200 的清炒，结论仍是未放行。
5. 证书台把甲锅证书作废，大事记可见作废记录；回记录台再选甲锅写入，被拒并提示证书已作废。
6. 证书台给锅改名，证书号保持不变，大事记多一条改名。
7. checker 能看记录台、证书台与大事记，但看不到写入、登记、改名、作废按钮（接口同样返回 403）。
